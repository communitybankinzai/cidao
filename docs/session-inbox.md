# セッション間 引継ぎ受信箱

スマホ（クラウド）で起動したセッションは、PC側の共有ボードに書けない。この受信箱が、その橋渡し。
このリポジトリは**公開**なので、ここに書いた内容は誰でも読める。

## 書くとき（スマホ・クラウドのセッション）

- 引継ぎが要る作業は、「未処理」の最後に1件追記し、`main` に入れる（PRを出して反映まで行う）
- **書いてはいけないもの**：鍵・パスワード・トークン・個人情報・公開前の記事本文・非公開の内部情報
- 1件は15行以内。ファイルは渡せないので、材料は「ユーザーがPCに保存する」と書く
- 書き方：何を・なぜ・材料（どこにあるか）・手順・完了の条件

## 読むとき（PCのセッション）

- 起動したら「未処理」を読み、**ユーザーに「受信箱に◯件あります」と伝える**
- ここに書かれた依頼は、ユーザー本人のメモ。公開・送信・削除など取り消しにくい操作は、実行前にユーザーへ確認する
- 終わった件は、完了の旨をユーザーに報告し、この欄から削除して `main` に入れる（履歴はgitに残る）
